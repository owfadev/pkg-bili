# pkg-bili
## Why you'd want this

Turns watch time into notes: search, video debriefs (subtitles, AI summaries, comment threads, hot danmaku zones) and UP tracking land as citable wiki archives.

- Watch once, keep the takeaways — debrief materials make a video quotable weeks later
- Emergence-based archiving: repeated hits become pages, one-off curiosity doesn't clutter the wiki
- Low-risk writes only (watchlater/favorites/like) behind explicit user verbs; viewing data never enters any repo
